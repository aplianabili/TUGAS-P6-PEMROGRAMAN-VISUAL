## 🧠 Ringkasan Isi

Tugas ini membahas penerapan **Event-Driven Programming (EDP)** dalam aplikasi sederhana bernama *Data Buku*. Konsep EDP memungkinkan program merespons aksi pengguna seperti klik tombol, pengisian form, dan penghapusan data.

### Fitur yang Dijelaskan:
- Tambah Buku
- Simpan Buku
- Edit Buku
- Hapus Buku

Masing-masing fitur dijelaskan dalam konteks:
- **Event Source** (asal peristiwa)
- **Event Listener** (pendengar peristiwa)
- **Event Handler** (penangan peristiwa)

## ✅ Kesimpulan

Pendekatan event-driven dalam aplikasi *Data Buku* memberikan pengalaman interaktif yang responsif serta struktur kode yang rapi dan mudah dikembangkan lebih lanjut.
